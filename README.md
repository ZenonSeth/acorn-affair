A top-down noir detective game with absurd humor, built for the Luanti Game Jam 2026.

# The Acorn Affair

## Status

The Acorn Affair is a work in progress.

## Requirements

- Luanti 5.18.0 or newer

## Install

Copy or clone this folder into the `games/` directory of your Luanti install (or your user data directory), then pick **The Acorn Affair** when creating a world.

## How it was made

- All the code was generated through claude code.
